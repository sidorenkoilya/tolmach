ТЕПЛОПОСТАЧ — односторінковий сайт паливних брикетів

Файли:
- index.html — структура та текст сторінки
- style.css — стилі та адаптивна верстка
- script.js — мобільне меню, форма та рік у футері
- assets/ — зображення для сторінки

Запуск: відкрийте index.html у браузері або завантажте всю папку на хостинг.
Форма заявки наразі готує лист у поштовій програмі; для автоматичного надсилання потрібне підключення серверної обробки.
Перед публікацією перевірте контактні дані, ціни та умови доставки.
